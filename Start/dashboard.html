About Me

My journey into technology started with curiosity about how software and websites actually work behind the scenes. As a Computer Science undergraduate, I became deeply interested in programming and problem solving. Learning languages like C++ and Java helped me understand the logic behind building software, while practicing Data Structures and Algorithms improved my ability to think efficiently and solve complex problems.

As I explored development further, I began building projects and experimenting with web technologies such as HTML, CSS, and JavaScript. Creating interfaces and turning ideas into working applications became something I genuinely enjoy. Every project I build teaches me something new about clean code, user experience, and how real-world applications are structured.

One of the projects I am currently working on is HiWorko, a workforce hiring platform designed to connect job seekers with employers in a simple and efficient way. The idea behind this project is to make the hiring process more accessible and streamlined. Working on HiWorko allows me to apply my development skills while learning how real-world platforms are designed, built, and improved.

My goal is to continuously grow as a developer and build technology that creates real impact. I am focused on improving my problem-solving skills, learning modern development tools, and working on meaningful projects. I am actively looking for opportunities such as Software Development Engineer (SDE) internships where I can gain industry experience and contribute to building innovative software solutions.
